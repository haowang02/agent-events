# 价格

费用在查询时按当前价格计算，修改价格立即作用于全部历史记录。

## 价格来源

模型价格依次取：

1. 「模型价格」页上设置的自定义价格。模型名不区分大小写。
2. 内置别名指向的模型的价格，适用于 models.dev 没有原厂定价的模型。
3. [models.dev](https://models.dev/) 参考价，忽略模型名中的 `provider/` 前缀：
   - 模型厂商自己对该模型 ID 的定价；
   - 否则厂商对同名规范模型（`canonical_model_id`）的定价；
   - 都没有时，所有提供商一致的定价。

   价格冲突时视为未定价。参考价缓存超过 24 小时会在启动时自动更新，也可在页面上手动更新。
4. 完整型号在参考价中不存在时，尝试下述后缀规则，使用基础型号的自定义价格或参考价。完整型号已有记录但价格冲突或不受支持时，不使用后缀兜底。

## 型号后缀兜底

后缀规则忽略大小写和 `provider/` 前缀，仅移除末尾的一个已知后缀：

| 模型家族 | 后缀 | 示例 |
| --- | --- | --- |
| 所有模型 | `-low`、`-medium`、`-high` | `claude-opus-5-5-high` → `claude-opus-5-5`；`claude-sonnet-5-5-low` → `claude-sonnet-5-5` |
| `gemini-` | `-a` 到 `-z` 的任意单个英文字母 | `gemini-3.8-flash-n` → `gemini-3.8-flash` |

基础型号必须有可用价格，否则仍为未定价。不递归移除后缀，也不改写版本号、日期或其他型号片段。原始模型名保持不变，价格来源显示「按基础型号计价」；设置原始模型名的自定义价格可覆盖兜底结果。

## 计价规则

- 价格可带一档长上下文价格：请求输入超过阈值时，整个请求按该档计价。
- 未设置的缓存读写价格显示为「—」，计费时按输入价计算。
- Claude 的 1 小时缓存写入按输入价 × 2 计算。
- Codex 的优先处理（`priority`，即快速模式）按标准价 × 2 计算。
- Claude 的快速模式只在「推理 / 档位」列标出，不改变计价：其倍率因模型而异。
